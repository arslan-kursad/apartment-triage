### Beklemediğim problem / sürpriz

- Connection string format: fly secrets set sırasında Neon URL
  formatı (postgresql://user:pass@host/db) yerine ADO.NET
  key-value format şart (Host=...; Database=...; Username=...;
  Password=...). Npgsql URI format kabul etmiyor production'da.
  Loom Q4 hammadde: "Deploy'da environment variable format
  farklılıkları — local secrets.json ile production secret
  format'ı aynı olmalı."

- fly launch yan etkisi: Kürşad'ın src/ApartmentTriage.Web/
  dizininden fly launch komutu hem ikinci bir fly.toml üretiyor
  hem root fly.toml'u override ediyor. app adı hanwas-ai'ye,
  [[checks]] silindi, min_machines_running=0 (Hangfire killer).
  Build'in monitoring'de DNS 192.168.1.1 dönünce tespit edildi.

- ASPNETCORE_HTTP_PORTS vs ASPNETCORE_URLS: Port numarası doğru
  olsa bile IPv6-only bind nedeniyle Fly proxy erişemiyor.
  ASPNETCORE_URLS=http://0.0.0.0:8080 explicit bind çözdü.
